r3PG Simulating F orest Growth using the 3-PG Process-Based V egetation
Model
Description
The r3PG package provides a flexible and easy-to-use interface for Fortran implementations of the
3-PGpjs (monospecific, evenaged and evergreen forests) or 3-PGmix (deciduous, uneven-aged or
mixed-species forests) forest growth models. The user can flexibly switch between various options
and submodules, to use the original 3-PGpjs model version for monospecific, even-aged and ever-
green forests and the 3-PGmix model, which can also simulate multi-cohort stands (e.g. mixtures,
uneven-aged) that contain deciduous species. The core function to run the model is run_3PG. For
more background, please consult the vignette via vignette(package = "r3PG")
