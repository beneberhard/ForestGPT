for fast and easy interaction with the model, and ‘Fortran‘ re-implementation facilitates computa-
tionally intensive sensitivity analysis and calibration. The user can flexibly switch between various
options and submodules, to use the original ‘3-PGpjs‘ model version for monospecific, even-aged
and evergreen forests and the ‘3-PGmix‘ model, which can also simulate multi-cohort stands (e.g.
mixtures, uneven-aged) that contain deciduous species.
This implementation of 3-PG includes several major variants / modifications of the model in par-
ticular the ability to switch between 3-PGpjs (the more classic model version for monospecific
stands) vs. 3-PGmix (a version for mixed stands), as well as options for bias corrections and δ13C
calculations (see parameters).
Value
either a 4-dimentional array or a data.frame, depending on the parameter df_out. More details on
the output is i_output
Note
The run_3PG also checks the quality of input data. When names, or structures are not consistent
with requirements it will return an error. Turn this off to optimize for speed.
